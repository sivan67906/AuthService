# AuthService Extras Bundle

This bundle contains:
- **Swagger UI Theme** (`swagger-theme/swagger-ui-custom.css`) and instructions to enable it.
- **Mermaid Diagrams** (`diagrams/*.mmd`) for architecture, auth flows, and docker/aspire topology.
- **Architecture_Diagrams.pdf** rendering of the diagram sources (textual) for easy sharing.

## Apply Swagger Theme
See `swagger-theme/Swagger_Styling_Readme.md`.

## View Mermaid Diagrams
Use any Mermaid viewer (VS Code: "Markdown Preview Mermaid Support") or online editors.
